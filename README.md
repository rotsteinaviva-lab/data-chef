# Data Chef: Recipes for Data-Wrangling & Visualization

Welcome to **Data Chef**, a blog-style website featuring step-by-step guides and "recipes" for data cleaning, processing, and visualization. 

You can view the live site here: [https://rotsteinaviva-lab.github.io/data-chef/](https://rotsteinaviva-lab.github.io/data-chef/)

---

## Built With

* **Website Framework:** Jekyll with the [Minimal Mistakes](https://github.io) theme.
* **Coding Assistant:** AI tools (Google Gemini) used to help write code tweaks, custom styles, and configuration adjustments.
* **Content Assistant:** AI tools (Google Gemini) used to help format lengthy data replication notes into simple steps.
* **Data Tools:** OpenRefine for data cleaning and Tableau for building dashboards.

## Repository Structure

* `_posts/` - Contains the markdown files for the data tutorials and blog posts.
* `data/` - Holds the project datasets used throughout the tutorials.
* `_config.yml` - The main configuration file for managing website settings and menus.
